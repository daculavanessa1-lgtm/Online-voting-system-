# Online Voting System

A lightweight single-file web application for voter registration, sign-in, single-vote enforcement, live result bars, and a basic admin reset view.

## Files in This Repository
- `index.html` — Complete web app (HTML, CSS, and JavaScript in one file).
- `prompt.md` — Original prompt and build specifications.
- `.gitignore` — Ignores system/editor temporary files.
- `README.md` — Project overview and setup instructions.

## Publish on GitHub Pages
1. Upload `index.html`, `README.md`, `prompt.md`, and `.gitignore` to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then save.
4. Open `https://<your-username>.github.io/<your-repo>/`.
